## 🌐 Sobre QPerú

QPerú es una red peruana que impulsa educación cuántica abierta, gratuita y
colaborativa, con presencia en Lima, Arequipa, Puno y Tarapoto. Formamos parte
del proceso de incorporación a la red internacional QWorld como capítulo
nacional (QCousin).

- Sitio web: [qperu.net](https://qperu.net)
- Instagram / LinkedIn / Facebook: @QPeru
